# M4 标签与元数据

生产入口为 `starsim.io.write_sequence`：传入 `prepare_sequence` 的结果及相机、运动、
传感器、PSF、光度、星表、抽样前的 `AppConfig`、生效配置及关键字参数 `derived_camera`（实际使用的 DerivedCamera）。内部只消费 `iter_frames`，逐帧写
FITS 后释放曝光数组；序列内仅保留源表和候选表，最后计算跨帧身份的有效 SNR。

`objects_XXX.npz` 是唯一真值，含 `schema_version=2` 和结构化 `sources_stars`、`sources_points`、`sources_streaks`、`stars`、`points`、`streaks` 表。
变长成员列表及字符串以 JSON 文本列保存，不依赖 pickle。使用
`starsim.io.load_objects` 读回 `FrameLabels`。全局源编号为本帧规范化顺序：星按缓存
索引，动目标按 track_id。曝光 owner 已映射到该编号；raw_group_id 原样保留。

`label_group_id` 按成员规范化编号元组排序生成；跨帧身份另用排序后的 TYC 成员集合
或 track_id。`snr_window: all` 累计全序列的身份相同且中心在图内的帧；整数 N 使用
以当前帧为中心的窗口，偶数 N 多取后一帧，边界截断。逐帧 ignore 不改变累计窗口。
`vx_ref/vy_ref` 是参考位置的中心差分，首末帧用单边差分，单位 px/帧。

稠密渲染：`render_dense(objects_seq, frame_k, H_k_to_target, cfg)`。
H 与用于配准图像的 H 相同；仅 reference 可用 cfg 的 `origin`、`size` 指定画布。
native 有意收窄为精确 float64 单位阵，2I、−I 均拒绝；cfg 出现 origin/size 键即拒绝，即使等于默认值。
默认 reference 画布是精确单应的并集。`valid` 按足迹与像素方块的正面积交集计算，
再按 stride 做 any 聚合。`collision` 每行是淘汰候选、最终获胜候选的编号，
`retained` 列出所有保留候选。不同类别的监督完全独立。

热力图等以 float16 压缩保存；`offset`、`streak_geom` 和 `motion` 保留 float32，H 为 float64：
长条纹长度和较大位移用 float16 时不能满足 0.01 px 的往返要求。保存热力图时，
把因 float16 量化而舍入到 1 的非峰肩部降到紧邻 1 的较小值，避免长椭圆产生伪峰。
FITS 使用 uint16、RICE_1 和原生 TAN WCS，astropy 读图为 `hdus[1].data`。

从落盘真值重新生成稠密标签：

```powershell
conda run -n genstarimg --no-capture-output python -m starsim.render_labels <输入序列目录> <新建或空的输出目录> --stride 4 --label-frame reference
```

独立验证器不导入 starsim，从缓存 RA/Dec、内参和姿态重新计算坐标，另用 astropy
验证元数据和 FITS 的 WCS；姿态的四元数、矩阵、指向/roll、Euler 和光轴互相核对，
北向位置角按完整周期比较并要求落在 (−π, π]。`H_k→ref` 由 `K R_ref R_kᵀ K⁻¹` 独立重建，
沿用生成器的归一化（姿态相同取单位阵，否则 `H[2,2] = 1`），以角点和中心的投影误差比较
帧 JSON、objects NPZ、`sequence.json` 运动段三处副本及 `H_to_canvas = T·H_to_ref`，
并检查画布原点和尺寸恰好覆盖重建的足迹。参考坐标从独立投影的原生中心映射得到，不读待验证
的 `x_ref`。所有输入和误差先做有限值检查。源—候选分区按全部类别检查：成员范围、重复、
反向编号、TYC/track_id 与身份一致，`has_flux=false` 的源必须是自己的 `no_flux` 候选。
没有已标注星时验证器照常通过，验收测试另行要求计数非零：

```powershell
conda run -n genstarimg --no-capture-output python scripts/verify_sequence.py <序列目录> --catalog cache/tycho1.npz
conda run -n genstarimg --no-capture-output python -m pytest tests/test_m4_labels.py -q
```

`artifacts/m4_report.json` 保存真实帧循环的落盘验证误差、环境和 stride 4 碰撞率。

## M4 审查后的数据契约

reference 先按本次 cfg 重新判定 labeled，再用中心的连续坐标检查
u=x−X₀、v=y−Y₀ 是否在 [−0.5,W−0.5) × [−0.5,H−0.5)。画布外记入 int64 `cropped`
（按 label_group_id 升序），不参与竞争，不写正峰、回归或 motion。
它的投影支撑与画布相交部分写入本类别 ignore；完全在外则不写 ignore。
原有 ignore 不进入 cropped。retained、collision loser、cropped 恰好划分本次 labeled，
loser 只出现一次且最终 winner 在 retained。native 的 cropped 恒为空，默认精确 H 的 union 也为空。
ignore 半开格区间的两端均限制到画布范围，空区间不写，正峰优先。
motion_mask 只要求当前 retained、上一帧同身份候选的原生中心在图内；上一帧状态和画布位置不影响它。

reference 的 H 先不指定 dtype 转数组，只接受 i/u/f 的 3×3，再转 float64；
渲染和记录都使用此原始矩阵，不归一化。元素有限且非全零。足迹四角为
(−0.5,−0.5)、(W−0.5,−0.5)、(W−0.5,H−0.5)、(−0.5,H−0.5)：
分子、分母有限，分母非零且同号，映射有限、相邻边叉积有限同号非零。
中心、端点、上一帧位置和 ignore 方框四角的每次映射都检查分子/分母/商有限、分母非零且与原图四角同号；跨无穷远线显式报错，不归入 cropped。
接受全负分母和镜像，不设近退化阈值。同一单应的不同整体尺度表示可能一个接受、另一个拒绝；
分母符号按浮点数判断，受舍入误差限制。

候选 sigma_psf 是候选质心处的局部 PSF 宽度 `psf.sigma_iso(x,y)`，不是混叠组整体光斑有效宽度，
独立于 D54；源级数值不变，重渲染直接读取候选表。`vis_frac == 0` 时可见几何无效，−1 只是占位。
population 的 entering/exiting 是每个目标的序列级值；objects 的同名字段是逐帧进入/退出事件。
候选按白名单显式构造，不继承首成员的源级字段。动目标的 46 个相等字段直接复制唯一成员，星候选仍按加权定义计算。

objects 源表读回合并并按全局 source_index 排序，要求 0…n−1 连续无重号。
旧格式缺少 schema_version 明确报“不支持旧格式”，不迁移。六张业务表在同一条序列内，
每类非空表字段集合和存储类别（bool、int64、float64、JSON 文本）一致；JSON Unicode 宽度可变。
空表固定为零行 id/U1 表，读回 []，不参与类型推断。不保证跨序列类型一致。
所有字段及嵌套列表/字典禁止 None 和非有限数；H_to_ref、size、frame_index 等表外数组也检查。

## 说明文件与校验

生产入口要求输出目录不存在或为空，按各帧文件 → sequence.json → 输入哈希 → 临时文件原子替换
`labels_manifest.json` 的顺序写入。CLI 要求独立的新建或空输出目录，输入序列只读，
不覆盖原 dense；`--stride` 接受任意 ≥1 的整数。
说明文件记录完整生效渲染 cfg（包含 CLI 覆盖）、完整 algorithm_versions()、objects schema，
sequence.json 和按帧顺序的 objects 的 SHA256，解析 origin/size/stride，逐帧原始 H，
以及规范 dense 文件名与 SHA256。dense 自身仅新增 H，不记录说明文件路径。
输出承诺仅包含 dense，FITS 和 meta 不在范围内；objects/meta 的状态统计仍为默认 cfg 快照，派生不回写。
`save_dense=false` 时没有说明文件，不能据此判定运行失败。

```python
from starsim.io import load_dense, validate_labels_manifest
validate_labels_manifest(derived_dir, sequence_dir)
dense = load_dense(derived_dir, sequence_dir, k)
```

生产路径两个目录相同；CLI 路径不同。N 取 len(sequence.motion.matrix)，要求 ≥2 且与其他帧数声明一致。
按 N 生成 sequence.json、objects_{k:03d}.npz、labels_{k:03d}.npz 清单（k≥1000 自然变宽），
严格核对说明文件名称、数量、顺序、输入/输出哈希和完整算法版本。
能发现文件缺失、文件被改、版本不一致；不能发现实现变更却不升版本、或文件和说明文件同时被篡改。
这是可跟随符号链接的一致性检查，不防篡改，也不保证文件位于目录之内。

## 预检与验证范围

写入前、建目录前、开始迭代前统一帧数 N≥2，要求 len(plan.stars)、sensor.n_frames、
effective.dataset.n_frames 相等。motion 文档中的逐帧数组长度 N，帧间数组 N−1。
population 的数组字段集合必须恰好是下面两组并集，新字段未登记即报错。T=len(track_id)，track_id 唯一，T=0 合法：

- (T,)：track_id kind strict p0_x p0_y speed direction_x direction_y accel_along curve_amp curve_shape sigma_cross sigma_along duty t_exp_eff angle_sigma_rad tier_design snr_design flux_design entering exiting never_full。
- (T,N)：delta_cross delta_along angle_jitter_rad jitter flux_e mag_eq x_ref y_ref x_c y_c x1 y1 x2 y2 x1_ref y1_ref x2_ref y2_ref L_true L_native angle_rad angle_native angle_ref in_image x_vis y_vis vis_x1 vis_y1 vis_x2 vis_y2 L_vis vis_frac truncated。

attempts 不是数组，不查形状。预检失败不产生输出，运行中途失败仍可能留下部分文件。
生产完整性检查显式抛异常，-O 下仍生效。同帧候选 identity 必须两两不同。
per_class_offset=false 和 streak_geom=false 在语义确定前拒绝。
LABELS_VERSION=3，objects schema_version=2，sequence.json schema_version=2，三者独立。

独立验证器检查几何、WCS、姿态、分区、状态和 ignore 原因配对；不读取 dense，
不重算标注规则和 SNR，不独立验证动目标的原生位置。
子进程仅检查 algorithm_versions 为 dict、键 str、值 type is int 且非负；父进程断言完整映射与当前版本严格相等。
不支持的相机模型和主点均抛 VerificationError，消息可区分。
相机派生元数据与 git 来源按下面 D70、D71 契约检查。

## D67–D73 冻结轮契约

CLI 覆盖后的 labels 子树先调用 `validate_label_cfg`，再创建输出目录。阈值有限且非负，
stride 为 ≥1 的 Python 整数，枚举、布尔及 D65 的 false 拒绝规则与配置入口一致。
说明文件先检查必需键和类型，再核对 config → 顶层 → 各帧 → dense 的 origin/size/stride；
缺键或不一致均抛 ValueError。

offset 写盘时在 float32 上裁剪到 `nextafter(float32(.5),float32(0))`，不转 float16。
像素中心往返误差保证限于 stride 1/4 的 native/reference 四种组合（<1e-3 px）；
不对任意大 stride 作统一精度承诺。stride 256、中心 0.03 的回归也要求 <1e-3 px。

渲染先跳过原有 ignore；只映射 labeled 中心，用相对坐标作连续裁剪，再编码并检查索引范围，
查 valid 后按 D58 竞争。正常 cropped 不做编码检查；native 越界报 ValueError。
原有 ignore、loser、cropped 仅按成员方框写 ignore；只有 retained 计算条纹端点、长度、方向和核宽度。
native 同样先拒绝 bool/字符串 H，再转 float64 并要求精确单位阵。
需要 motion、k>0、上一帧同身份且 in_image 的 retained 首次出现时，才构造 prev_H，
按上一帧尺寸做完整单应校验并缓存四角符号。

候选公共 31 字段：
`label_group_id class_id members components blended identity stable_key representative_member x y x_ref y_ref flux_e sigma_psf in_image has_flux dominant_source saturated in_foreign_sat in_defect_sat group_peak_row group_peak_col s_group sigma_local snr snr_eff identity_frame_count status_default ignore_reason_default ra dec`。

星额外 2 字段：`vmag member_identity_counts`。

动目标额外 39 字段：
`track_id mag_eq tier_design tier_measured duty_eff t_exp_eff x1 y1 x2 y2 x1_ref y1_ref x2_ref y2_ref L_true L_native angle_rad angle_ref x_vis y_vis vis_x1 vis_y1 vis_x2 vis_y2 L_vis vis_frac vis_x1_ref vis_y1_ref vis_x2_ref vis_y2_ref x_vis_ref y_vis_ref L_vis_ref vx_ref vy_ref truncated entering exiting never_full`。

非空候选表字段集合必须严格等于公共字段与本类别额外字段的并集；多、少均拒绝。
每个动目标恰有一个成员，`x y x_ref y_ref flux_e ra dec` 和全部 39 额外字段与成员逐值相等。
源级 id、TYC、方框、峰格、来源、截断标志等通过 members 回查；代表成员由 representative_member 指出。
非空源表沿用序列内类型登记，不设白名单。全部空表 dtype 精确为 `[("id","<U1")]`，零行。
六张表及 schema_version/frame_index/size/H_to_ref 均必需；schema 为零维整数 2；
frame_index 为零维非负整数；size 为 (2,) 正整数；H_to_ref 为有限 float64 (3,3)。
各表 class_id 为对应整数类别。读取器抛 ValueError；独立验证器同样检查并抛 VerificationError。

写入前要求 `Camera.from_derived(derived_camera)` 与 camera 各字段相等。
sensor 的 height/width/cx/cy 等于 camera；background_e/vignetting/prnu/dark_e 为 (H,W)，
row_offset_e 为 (H,)，col_offset_e 为 (W,)，hot_row/hot_col/hot_kind/hot_level_a/hot_level_b/hot_p_flip
为 (n_hot,)，hot_state 为 (n_hot,N)，dead_row/dead_col 为 (n_dead,)；坏像素坐标为范围内整数。
这些检查全部在创建目录和开始帧迭代前完成。

sequence.json 记录实际 derived_camera；生成开始时，从 starsim 包目录定位 git 仓库根和 HEAD，
记录 git_commit 与 git_dirty。dirty 使用 `status --porcelain --untracked-files=all -- starsim scripts configs tests`，
包含未跟踪文件、不含 artifacts；任一步失败两字段均为 null。查询不依赖调用者 cwd。

D72 不改变数值和随机流：序列共用一次星表索引；主导源仅筛查方框覆盖代表格的源；
assign_status 按身份分组，all 窗口只求和一次，有限窗口保留原帧序与求和顺序。
write_sequence 与 CLI 每份 cfg 只判定一次状态，各帧用 `_render_frame`；stride 4 复用状态。
公开 render_dense 仍 deepcopy 并重判，保证调用者输入不变。

冻结要求：D67–D72 回归与完整测试通过，报告含 blended>0 的视场、cropped>0 的 reference 派生、
说明文件校验、stride 4 碰撞率和实际性能测量。先提交代码，四个代码目录干净后生成报告，报告单独提交。
报告 git_commit 非空、git_dirty=false；来源提交是 HEAD 祖先，来源到 HEAD 的四个代码目录无差异，
验收当下工作区干净后才冻结。冻结后字段或数值改动按 D42 升版。
