# M5 批量生成、划分和重放

生产入口：`starsim.generate.generate_sequence(AppConfig, seed, index, out_dir)`。
相机只从 AppConfig 构造。抽样及写盘前逐字段重算检查 sensor、derived 和 camera.derived。

```powershell
conda run -n genstarimg --no-capture-output python -m starsim.generate --n-sequences 10 --workers 2 --seed 20261031 --out-dir D:/StarProcess/GenStarImgs/.tmp/m5_production_v2
conda run -n genstarimg --no-capture-output python -m starsim.generate --n-sequences 10 --workers 2 --seed 20261031 --out-dir D:/StarProcess/GenStarImgs/.tmp/m5_production_v2 --resume
conda run -n genstarimg --no-capture-output python -m starsim.generate --replay D:/StarProcess/GenStarImgs/.tmp/m5_production_v2/seq_000000/sequence.json --out-dir D:/StarSimData/replay
```

支持 `--camera`、`--config`、`--catalog`；CLI 覆盖先经过既有配置校验。
M5 输出 FITS RICE，其他 image_format 或 export_registered=true 明确拒绝。

## 划分和接受条件

split 2 的球冠只使用 `dataset/caps` 流，与序列总数、fractions 和归属流独立。
sky 模式按低、中、高银纬循环放置互不相交的球冠，在整个球面均匀抽样。
面积由 32768 点等面积 Fibonacci 积分估计。
`dataset/assign` 流只抽一次 train/val/test 的平局顺序；第 i 条选择
`fraction * (i+1) - assigned_count` 最大的划分，float64 精确比较，相等时按该顺序。
共同前缀的归属不随数据集扩充改变；random 模式使用同样的调度，不抽球冠。
原目录不支持扩容，n_sequences 仍属于续跑签名。

motion 3 在 galactic_latitude 之后直接判定 sky_split、min_labeled_stars，不使用回调。
最低星数的预曝光口径：中间帧中心在图内且 m≤本序列 mag_limit 的星表星数。
生产入口同时传入球冠和星表；可选参数均为 None 的底层默认路径与 motion 2 逐位相同。
config_effective.pointing.split_constraints 子记录 schema 1 保存 mode、split、caps、guard_deg；
同级保留 min_labeled_stars。外层 sequence schema 2、objects schema 2 和 labels 3 不变。
重放核对环境、算法版本、星表、RNG，以及重新计算的相机和划分条件。

最终逐对断言 train 与 val/test 中间帧光轴距离 >11.6°。
三方均达到 min_seqs_for_assert 才硬断言每帧已标注星数的中位数最大/最小<1.3；不足则警告。
random 模式保留按序列比例分配，不施加天区隔离断言。

## 断点和目录

每条序列在 `.seq_XXXXXX.partial` 内生成，写完 complete.json 后原子重命名为 seq_XXXXXX。
complete.json 列出必需文件 SHA256、耗时、峰值 RSS、字节数及星数。
dataset.json 每完成一条序列原子更新；父进程未登记但目录已提交时可恢复登记。
续跑精确核对配置、环境、版本、星表与区域几何，核对已完成序列的必需文件集合及哈希；
部分序列重新生成，损坏的已完成序列报错。输出目录只允许新建/空目录，已有数据必须显式 --resume。
workers=min(配置值, floor((可用内存−3 GiB)/4 GiB))；采用 spawn，每个工作进程只生成一条序列。

## 标签等价性和计时

网格索引只缩小候选集合，按原始闭区间方框精确过滤；贡献求和及规范索引平局规则不变。
并集画布每序列计算一次，复用到两种 stride、metadata 和说明文件。
write_sequence 只调用一次跨帧 assign_status，帧级元数据在状态完成后补计数。
timing.json 的生成阶段包括标签构建、跨帧状态、dense、FITS 调用、objects NPZ、dense NPZ、帧 JSON 和其他；
其他为阶段总时长减已列项（含曝光渲染、sequence JSON 和说明文件），不含 timing.json 自身序列化。
worker 提交阶段包括哈希、complete.json 写入加重命名、其他，各项之和等于阶段总时长。
两阶段不重叠，均用 perf_counter，不拆分纯压缩与纯 I/O。

数据集 schema 2 先于签名比较检查；schema 1 或缺失字段立即拒绝且不写旧目录，不迁移。
续跑签名不含 workers 和 out_dir；每条序列检查目录编号对应的 RNG、种子、归属、约束、来源、版本、环境、星表和全部文件集合及哈希。
audit 光轴从运动中间帧矩阵第三行重算，逐帧 labeled 星数从 objects 重算，并与 complete.json 精确比较。
入口 seed 必须等于配置种子。

dataset.json 保存每次启动的运行段：UTC 日期时间、单调时钟活动时长、running/completed/failed/interrupted 状态。
续跑将未结束的旧段标为 interrupted，最后刷新时长为下界；报告分别保存累计活动时间、首次启动到完成历时、成功序列耗时和。
无运行段记录的历史耗时不可恢复，不推算。
父进程每 0.1 s 采样可用内存，记录至少两个 worker 任务同时活动时的最低值；每 worker 上报峰值。
4 GiB 是代表性配置经验预算，不是所有配置的内存上界。

冻结实现基线由 ad66eba 重建，覆盖原固定 disk fixture、8 帧报告输入、reference union、
reference 裁剪、两种 stride、闭边界与平局用例；同时比较逐帧最终统计。
输入 YAML 的 SHA256 统一按 LF 换行计算（git archive 与 Windows 工作区换行不同），星表 NPZ 按原始字节计算。

```powershell
conda run -n genstarimg --no-capture-output python -m tests.m5_baseline artifacts/m5_baseline.json --freeze
conda run -n genstarimg --no-capture-output python -m tests.m5_baseline artifacts/m5_baseline.json --compare
conda run -n genstarimg --no-capture-output python -m pytest -m "not slow" --basetemp=.tmp/pytest_m5
conda run -n genstarimg --no-capture-output python -m tests.m5_production_acceptance .tmp/m5_production_v3
```

artifacts/m5_migration.json 保存 M3 默认路径两组比较及迁移前后各序列规范化哈希；
基线只改组级 motion 2→3，保留全部序列数据，M2 报告段记录迁移理由，M4 历史报告不改。
artifacts/m5_report.json 保存 4096 px、300 mm、10 序列的耗时、磁盘、分段标签计时，
以及两个启动前分别设置 PYTHONHASHSEED=1/2 的独立解释器的 30 个输出文件哈希。

D81 验收每次创建唯一空目录，两个独立解释器分别复现 train、val、test 各一条，与生产目录比对 FITS 和两种 NPZ。
生产目录逐条调用 verify_completed；生成来源要求非空 git_commit、git_dirty=false、祖先关系且 starsim/configs 无差异。
验收报告另记干净的 starsim/scripts/configs/tests 来源。提交代码后生成生产数据和报告，再单独提交报告，最后检查祖先关系、四目录无差异和干净工作区。
旧版 M5 实测不再作为当前验收证据，最终结果以重新生成的报告为准。
P-8 星数预检、P-9 guard 与 11.6° 的关系、P-10 扩容契约仍待定；审计保持 11.6°。
